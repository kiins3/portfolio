# Portfolio — Tran Hai Dang

Personal site: projects, experience and skills.

**Next.js 16 (App Router) · TypeScript · Tailwind CSS 4** — fully static, deployed on Vercel.

## Edit content

All text lives in [`src/data/profile.ts`](src/data/profile.ts): profile, experience, projects (add a `{ label: "Live demo", href: "..." }` link once a project is deployed) and skills.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Import the repository on [vercel.com/new](https://vercel.com/new). No settings or environment variables needed.
